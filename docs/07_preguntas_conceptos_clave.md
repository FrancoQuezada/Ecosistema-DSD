# Preguntas y conceptos clave

Este documento resume las preguntas que los equipos deben responder a lo largo del taller y los conceptos que deben manejar para construir un MVP digital funcional.

## Preguntas clave por dimensión

### Desafío y solución

- ¿Qué desafío previamente formulado aborda el proyecto?
- ¿Cuál es el usuario o beneficiario principal?
- ¿Qué tarea concreta debe facilitar la solución?
- ¿Qué fricción reduce?
- ¿Qué decisión mejora?
- ¿Qué proceso digitaliza, automatiza o apoya?
- ¿Por qué esta solución debería existir?

### Propuesta de valor

- ¿Qué valor entrega la solución?
- ¿A quién se lo entrega?
- ¿En qué momento del proceso se usa?
- ¿Qué alternativa existe actualmente?
- ¿Qué mejora ofrece frente a esa alternativa?
- ¿Cuál es la hipótesis crítica que el MVP debe validar?

### MVP y alcance

- ¿Cuál es el flujo mínimo funcional?
- ¿Qué funcionalidades son indispensables?
- ¿Qué funcionalidades son deseables pero no críticas?
- ¿Qué quedará explícitamente fuera del MVP?
- ¿Qué se puede simular?
- ¿Qué debe estar realmente implementado?
- ¿Qué evidencia indicará que el MVP funciona?

### UX/UI

- ¿El usuario entiende qué debe hacer?
- ¿Cuáles son las pantallas mínimas necesarias?
- ¿El flujo de navegación es claro?
- ¿Los formularios piden solo lo necesario?
- ¿La solución puede ser usada sin explicación del equipo?
- ¿Existen barreras básicas de accesibilidad?

### Ambiente de desarrollo

- ¿El repositorio está creado y organizado?
- ¿El README permite entender el proyecto?
- ¿Los commits muestran avance real?
- ¿El equipo trabaja con un flujo común?
- ¿La IA se usa con revisión y trazabilidad?
- ¿La demo puede ejecutarse o desplegarse?

### Arquitectura

- ¿Qué componentes tiene la solución?
- ¿Qué ocurre en el frontend?
- ¿Qué ocurre en el backend?
- ¿Dónde vive la información?
- ¿Qué servicios externos se usan?
- ¿Qué variables de entorno se requieren?
- ¿Cómo se despliega la solución?
- ¿Qué riesgos técnicos existen?

### Datos, seguridad y privacidad

- ¿Qué datos son estrictamente necesarios?
- ¿Qué datos no deberían capturarse?
- ¿Qué datos son personales o sensibles?
- ¿Quién puede ver, editar o eliminar información?
- ¿Qué ocurre si los datos se filtran?
- ¿Qué ocurre si los datos son incorrectos?
- ¿Cómo se protege la información?
- ¿Qué permisos o roles se requieren?

### Desarrollo funcional

- ¿El flujo principal funciona?
- ¿Los datos se capturan correctamente?
- ¿La solución maneja errores básicos?
- ¿La navegación es consistente?
- ¿El MVP puede ser usado por una persona externa?
- ¿El código queda organizado para continuidad?

### IA aplicada

- ¿Qué tareas fueron apoyadas por IA?
- ¿Qué prompts o instrucciones fueron relevantes?
- ¿Qué respuestas se aceptaron?
- ¿Qué respuestas se modificaron?
- ¿Qué respuestas se descartaron?
- ¿Qué errores produjo la IA?
- ¿Cómo se verificó el resultado?
- ¿La IA aceleró el desarrollo sin reducir el control del equipo?

### Validación

- ¿Qué se probó?
- ¿Con quién se probó?
- ¿Qué errores aparecieron?
- ¿Qué feedback se recibió?
- ¿Qué patrones se identificaron?
- ¿Qué mejoras se priorizaron?
- ¿Qué evidencia muestra que la solución entrega valor?

### Ética e impacto

- ¿A quién beneficia la solución?
- ¿A quién podría perjudicar?
- ¿Qué riesgos de exclusión existen?
- ¿Hay sesgos posibles en datos o uso?
- ¿Qué decisiones no deberían automatizarse?
- ¿Qué información debe transparentarse al usuario?
- ¿Qué responsabilidades tiene el equipo desarrollador?

### Adopción y continuidad

- ¿Quién usaría realmente la solución?
- ¿Quién la mantendría?
- ¿Qué proceso organizacional cambia?
- ¿Qué barreras de adopción existen?
- ¿Qué condiciones se requieren para pilotear?
- ¿Qué mejoras son necesarias para una siguiente versión?
- ¿Qué criterios permitirían decidir continuidad o discontinuidad?

### Comunicación y demo

- ¿La presentación explica el valor en poco tiempo?
- ¿La demo muestra funcionamiento real?
- ¿La audiencia entiende qué se logró?
- ¿La evidencia de validación es clara?
- ¿Los riesgos y límites están declarados?
- ¿El roadmap es realista?
